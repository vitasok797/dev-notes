# WebView SCADA

Проект представляет собой трехкомпонентное приложение, где расчетное ядро отделено от графического интерфейса. Фронтенд-часть полностью оптимизирована для генерации искусственным интеллектом (AI-generated) за счет использования связки **Vue 3 + Vue Konva**, а в качестве легковесного десктопного контейнера используется **Tauri**, обеспечивающий минимальное потребление ОЗУ и малый вес сборки.

### 1. Архитектурная схема системы

```
  [ Компонент 1: Расчетное ядро (C#) ]
       │                      ▲
       │ (Данные:             │ (Команды:
       │  gRPC / WebSockets)  │  gRPC / WebSockets)
       ▼                      │
  [ Компонент 3: Рантайм Визуализации (Tauri) ]
       ▲
       │ (Загружает единый JSON-файл схемы)
       │
  [ Компонент 2: Редактор схем (Tauri) ]
```

* **Компонент 1 (Бэкенд ядра):** Расчетное приложение на **C#** с поддержкой плагинов. Опрашивает оборудование и передает потоковые значения тегов по протоколам **gRPC** или **WebSockets**.
* **Компоненты 2 и 3 (Интерфейс):** Объединены в **одно приложение на Tauri** с двумя режимами работы: «Дизайнер» (Редактор) и «Исполнение» (Рантайм-визуализация).

### 2. Целевой технологический стек фронтенда

* **Платформа:** **Tauri** (Использует системный движок Windows WebView2/Edge Chromium. Вес приложения — 5–15 МБ, потребление ОЗУ — 30–50 МБ).
* **Фреймворк и реактивность:** **Vue 3 (Composition API)** + **Pinia** (Глобальное хранилище тегов). Данные из сети записываются в Pinia, откуда мгновенно подхватываются интерфейсом.
* **Стилизация обвязки:** **Tailwind CSS** (Позволяет AI генерировать компактные десктопные интерфейсы панелей прямо в HTML-классах).
* **Графический холст:** **Vue Konva** (Официальная обертка над Konva.js). Позволяет ИИ описывать графику (линии, фигуры) в виде привычных Vue-компонентов (`<v-stage>`, `<v-layer>`, `<v-line>`) внутри HTML5 Canvas.

### 3. Библиотеки для нативного и строгого UI (Обвязка редактора)

Для создания панелей свойств, дерева объектов и меню используются готовые библиотеки компонентов, которые ИИ знает в совершенстве:

1. **Shadcn-vue** — если нужен ультрасовременный, строгий дизайн в стиле VS Code. Отлично кастомизируется силами AI под компактный интерфейс.
2. **Element Plus** — если нужен классический «промышленный» интерфейс инженерных программ. Имеет огромный набор готовых компонентов (древовидные списки тегов `TreeView`, сложные таблицы, формы ввода).

### 4. Два варианта реализации бэкенд-процесса в Tauri

Поскольку нативный слой Tauri написан на **Rust**, архитектура взаимодействия фронтенда с C#-ядром может быть реализована двумя способами:

* **Вариант 1: Сетевой шлюз на Rust (Нативный подход Tauri)**
    * *Как это работает:* Внутри Tauri-приложения пишется небольшой сетевой клиент на Rust (gRPC или WebSocket). Он подключается к C#-ядру, слушает поток тегов и транслирует их во фронтенд (Vue 3) через встроенную систему событий Tauri (`tauri::Emitter::emit`).
    * *Плюсы:* Максимальная безопасность типов, высокая производительность, фронтенд не думает о сетевых протоколах и просто слушает события `window.listen()`.
* **Вариант 2: Прямой микросервис C# (Подход Sidecar)**
    * *Как это работает:* Расчетное ядро C# компилируется в исполняемый файл и зашивается внутрь Tauri как сторонний бинарник (**Sidecar**). При старте интерфейса Tauri автоматически запускает этот `.exe` файл в фоновом процессе ОС. Фронтенд на Vue 3 открывает WebSocket-соединение напрямую к локальному порту этого процесса в обход Rust-слоя.
    * *Плюсы:* Минимальное количество Rust-кода (упрощает генерацию для AI), C# и интерфейс поставляются в одном дистрибутиве, фронтенд общается напрямую с бэкендом по сети.

### 5. Два варианта интеграции компонентов (Насосы, Резервуары) на холст

*   **Вариант А: Рендеринг компонентов через HTML-слой (Overlay поверх Canvas)**
    Холст Canvas используется **только для рисования линий труб** и сетки фона. Все насосы и датчики — это **обычные HTML/Vue компоненты** (использующие Tailwind и иконки Lucide), которые абсолютно позиционируются поверх холста через `v-for="p in pumps" :style="{ left: p.x, top: p.y }"`. Перетаскивание объектов меняет их координаты во Vue, а Canvas под ними просто перерисовывает подходящие трубы.
*   **Вариант Б: Полная компиляция компонентов в Canvas-графику (Чистый Vue Konva)**
    Все насосы и резервуары описываются специализированными тегами графики внутри Vue Konva. Они полностью рендерятся внутри единого Canvas-контекста. ИИ создает файл компонента `Pump.vue`, где тело насоса — это `<v-circle>`, текстовая метка — `<v-text>`, а крыльчатка — `<v-shape>`. Вся анимация и изменения цвета перерисовываются движком Konva на аппаратном ускорении видеокарты.

### 6. Концепция линий связи (Трубопроводы, Кабели)

Линии связи являются самостоятельными графическими объектами на холсте.
* **Геометрия:** Строго ортогональная (под прямыми углами). Пользователь кликами мыши вручную расставляет точки излома.
* **Реализация:** Отрисовывается через компонент `<v-line :config="{ points: [...] }" />`. 
* **Ортогональный замок (AI-логика):** При движении мыши в режиме черчения ИИ программно выравнивает текущую координату по оси X или Y относительно предыдущей точки, запрещая диагональные линии. При перемещении привязанных графических объектов крайние точки линии автоматически удлиняются, сохраняя прямой угол.
* **Динамика:** При изменении тега в Pinia, линия меняет цвет (`stroke`) или включает анимацию движения жидкости (через смещение свойства `dashOffset`).

### 7. Структура данных (JSON-схема)

Продукт работы Редактора — единый плоский JSON-файл, содержащий настройки холста и массив всех элементов на нем:

```json
{
  "canvas": { "width": 1920, "height": 1080, "background": "#1e293b" },
  "elements": [
    {
      "id": "pump_1",
      "type": "widget",
      "widgetType": "industrial-pump",
      "x": 120,
      "y": 250,
      "bindings": { "isWorking": "CoreApp.Station1.PumpStatus" }
    },
    {
      "id": "pipe_main",
      "type": "polyline",
      "points": [
        { "x": 150, "y": 250 },
        { "x": 400, "y": 250 },
        { "x": 400, "y": 500 }
      ],
      "staticProps": { "strokeWidth": 6, "stroke": "#64748b" },
      "bindings": { "stroke": "CoreApp.Station1.PipeColor" }
    }
  ]
}
```
