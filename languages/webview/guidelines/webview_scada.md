# WebView SCADA

Проект представляет собой трехкомпонентное приложение, где расчетное ядро отделено от графического интерфейса. Фронтенд-часть полностью оптимизирована для генерации искусственным интеллектом (AI-generated) за счет использования связки **Vue 3 + Vue Konva**, что позволяет описывать мнемосхемы декларативно и сохранять мощь реактивности.

### 1. Архитектурная схема системы

```
  [ Компонент 1: Расчетное ядро (C#) ]
       │                      ▲
       │ (Данные:             │ (Команды:
       │  gRPC / WebSockets)  │  gRPC / WebSockets)
       ▼                      │
  [ Компонент 3: Рантайм Визуализации (Electron) ]
       ▲
       │ (Загружает единый JSON-файл схемы)
       │
  [ Компонент 2: Редактор схем (Electron) ]
```

* **Компонент 1 (Бэкенд):** Расчетное приложение на **C#** с поддержкой плагинов. Опрашивает оборудование и передает потоковые значения тегов (и принимает команды) по протоколам **gRPC** или **WebSockets**.
* **Компоненты 2 и 3 (Интерфейс):** Объединены в **одно приложение на Electron** с двумя режимами работы: «Дизайнер» (Редактор) и «Исполнение» (Рантайм-визуализация).

### 2. Целевой технологический стек фронтенда

* **Платформа:** **Electron** (Обеспечивает доступ к файловой системе для сохранения JSON-схем и работу с сетью без ограничений CORS).
* **Фреймворк и реактивность:** **Vue 3 (Composition API)** + **Pinia** (В качестве глобального хранилища тегов). Сетевой слой Electron записывает данные от C# в Pinia, откуда они мгновенно подхватываются интерфейсом.
* **Стилизация обвязки:** **Tailwind CSS** (Позволяет AI генерировать компактные интерфейсы панелей прямо в HTML-классах).
* **Графический холст:** **Vue Konva** (Официальная обертка над движком Konva.js). Позволяет ИИ не писать сложный императивный JS-код для Canvas, а описывать графику (линии, фигуры) в виде привычных Vue-компонентов (`<v-stage>`, `<v-layer>`, `<v-line>`).

### 3. Библиотеки для нативного и строгого UI (Обвязка редактора)

Для создания панелей свойств, дерева объектов, меню и модальных окон используются готовые библиотеки компонентов, которые ИИ знает в совершенстве. Выбор зависит от требований к дизайну:

1. **Shadcn-vue** — если нужен ультрасовременный, строгий, минималистичный дизайн в стиле VS Code. Идеально сочетается с Tailwind CSS, компоненты легко кастомизируются силами AI под компактный десктопный интерфейс.
2. **Element Plus** — если нужен классический «промышленный» интерфейс инженерных программ. Имеет огромный набор готовых тяжелых компонентов из коробки (сложные древовидные списки тегов `TreeView`, продвинутые таблицы с фильтрацией, формы ввода параметров).

### 4. Два варианта интеграции компонентов (Насосы, Резервуары) на холст

#### Вариант А: Рендеринг компонентов через HTML-слой (Overlay поверх Canvas)
Холст Canvas (`Vue Konva`) используется **только для рисования линий труб** и сетки фона. Все насосы, задвижки и датчики — это **обычные HTML/Vue компоненты** (использующие Tailwind, иконки Lucide и т.д.), которые абсолютно позиционируются поверх холста.
* *Как это работает для AI:* ИИ генерирует массив виджетов поверх канваса через `v-for="p in pumps" :style="{ left: p.x, top: p.y }"`. Перетаскивание объектов меняет их координаты во Vue, а Canvas под ними просто перерисовывает подходящие трубы.

#### Вариант Б: Полная компиляция компонентов в Canvas-графику (Чистый Vue Konva)
Все насосы и резервуары описываются специализированными тегами графики внутри Vue Konva. Они полностью рендерятся внутри единого Canvas-контекста.
* *Как это работает для AI:* ИИ создает файл компонента `Pump.vue`, где тело насоса — это `<v-circle>`, текстовая метка — `<v-text>`, а крыльчатка — `<v-shape>`. Вся анимация вращения и изменение цвета привязаны к `props` и реактивно перерисовываются движком Konva на аппаратном ускорении видеокарты.

### 5. Концепция линий связи (Трубопроводы, Кабели)

Линии связи являются самостоятельными графическими чрезвычайными объектами на холсте (не привязанными к жесткой топологии графа).
* **Геометрия:** Строго ортогональная (под прямыми углами). Пользователь кликами мыши вручную расставляет точки излома.
* **Реализация:** Отрисовывается через компонент `<v-line :config="{ points: [...] }" />`. 
* **Ортогональный замок (AI-логика):** При движении мыши в режиме черчения ИИ программно выравнивает текущую координату по оси X или Y относительно предыдущей точки, запрещая диагональные линии. При перемещении графических объектов крайние точки линии автоматически удлиняются, сохраняя прямой угол.
* **Динамика:** При изменении тега в Pinia, линия меняет цвет (`stroke`) или включает анимацию движения жидкости/тока (через смещение свойства `dashOffset`).

### 6. Структура данных (JSON-схема)

Продукт работы Редактора — единый плоский JSON-файл, содержащий настройки холста и массив всех элементов на нем:

```json
{
  "canvas": { "width": 1920, "height": 1080, "background": "#1e293b" },
  "elements": [
    {
      "id": "pump_1",
      "type": "widget",
      "widgetType": "industrial-pump",
      "x": 120,
      "y": 250,
      "bindings": { "isWorking": "CoreApp.Station1.PumpStatus" }
    },
    {
      "id": "pipe_main",
      "type": "polyline",
      "points": [
        { "x": 150, "y": 250 },
        { "x": 400, "y": 250 },
        { "x": 400, "y": 500 }
      ],
      "staticProps": { "strokeWidth": 6, "stroke": "#64748b" },
      "bindings": { "stroke": "CoreApp.Station1.PipeColor" }
    }
  ]
}
```
